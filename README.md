# Skill Dossier Generator

Parses CVs and generates skill dossiers and portfolios.

## Features

- CV parsing and analysis
- PDF export and sharing
- Admin roles and users

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/skill-dossier-generation.git
cd skill-dossier-generation
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint
